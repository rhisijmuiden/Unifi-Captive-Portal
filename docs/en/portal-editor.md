# Portal editor

**English** · [Nederlands](../nl/portaal-editor.md)

The portal editor is where you design the page guests see when they join your Wi-Fi. What you see in the editor is exactly what guests get: the editor and the guest page use the same renderer.

Open it in your own environment under **Captive portals → Portal editor**.

## The screen

| Part | What it does |
| --- | --- |
| **Blocks** (left) | The building blocks: logo, Wi-Fi icon, heading, text, image, link button, divider and spacing. Drag a block onto the phone, or click it to add it at the bottom. |
| **Phone** (middle) | The live page. Drag blocks up and down to change the order. Click a block to edit it. The buttons above the phone switch between a phone and a desktop view. |
| **Block / Style** (right) | *Block* shows the settings of the selected block. *Style* holds the colours, background, font, rounded corners and card style of the whole page. |
| **Texts in** | Switches the language you are writing in. Every text block has its own text per language. |

The **sign-in block** is always on the page and cannot be removed: it holds the ways guests connect (free, e-mail, voucher, payment or Facebook). Which ones are shown is set under **Access & sign-in**. You can move it, for example below an image.

## Templates

Click **Templates** to start from a ready-made design: *Modern*, *Minimal*, *Hotel*, *Café*, *Business* or *Event*. A template replaces the current design; nothing is saved until you click **Save**, so you can try them out freely.

## Images and logos

Upload PNG, JPG, WebP, GIF or SVG files of up to 2 MB. They are stored on the platform itself, so guests can load them before they are online. External image links are not used, because guests cannot reach the internet yet.

## Languages

Guests choose their language at the bottom of the page. The languages on offer are set under **Access & sign-in → Languages**; the first one is the default. If a text is empty in a language, the guest sees the text of the default language.

## Tips

- Keep the page short: guests want to get online. A logo, a heading, one sentence and the sign-in block is usually enough.
- Use a strong contrast between the accent colour and the button text. The editor shows the result straight away.
- Leaving the editor with unsaved changes asks for confirmation.
